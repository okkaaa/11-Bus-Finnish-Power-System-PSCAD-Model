# 11-bus-Finnish-Power-System-PSCAD-model

This simulation model is associated with a Master's thesis studying a large scale underfrequency event in the Finnish power system. The fault scenario is the islanding of the Finnish system from the Nordic synchronous area when the active power import is 1300 MW. The simulated system is described in-depth in the thesis.

The model utilises grid-following inverter models by Rick W. Kenyon from the publication "Open-Source PSCAD Grid-Following and Grid-Forming (Zero-Inertia Capable) Inverters" (doi: 10.1109/KPEC51835.2021.9446243).

The topology of the grid is based on the publication "Battery Energy Storage System for Transient Frequency Enhancement of a Large-Scale Power System" by Ujjwal Datta (doi: 10.1109/AUPEC.2017.8282465).
